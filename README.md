# 台北車站室內導航系統

本專案為台北車站室內導航系統，整合 Wi-Fi 定位、PDR 行人航位推算、跨樓層導航與 Android App。

## 線上系統

https://taipei-station-indoor-navigation.onrender.com

## 主要功能

- Wi-Fi 室內定位
- PDR 步行定位
- Wi-Fi + PDR 混合定位
- 跨樓層路徑導航
- Android WebView App
- SOS 功能
- DQN 路徑導航
